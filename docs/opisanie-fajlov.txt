================================================================================
  ОПИСАНИЕ ФАЙЛОВ ПРОГРАММЫ WinOpt (Оптимизация Windows)
  Версия: 1.1.0
================================================================================

Этот документ описывает назначение каждого файла в проекте.
Путь к проекту: D:\Optimization_My_Windows


КОРЕНЬ ПРОЕКТА
================================================================================

requirements.txt
  Внешние библиотеки Python:
    psutil         — процессы, память, диски, сеть, батарея;
    customtkinter  — современный интерфейс (тёмная тема, скруглённые элементы).
  Установка: python -m pip install -r requirements.txt

assets\winopt.ico
  Иконка программы для ярлыка и заголовка окна.

assets\winopt-icon.png
  Исходное изображение иконки (PNG).

docs\README.txt
  Основная документация: разделы, команды CLI, что изменилось, ограничения.

docs\opisanie-fajlov.txt
  Этот файл.


ПАПКА winopt\ — ОСНОВА
================================================================================

winopt\__init__.py
  Инициализация пакета. Версия: __version__ = "1.1.0".

winopt\__main__.py
  Точка входа: python -m winopt
  Без аргументов — окно программы, с аргументами — консольный режим.

winopt\cli.py
  Консольный интерфейс. Команды: scan, resources, startup, gui (--page),
  shortcut, cleanup, disk (--drive), large-files, health, history,
  duplicates, network, programs, services, restore-point, report.

winopt\gui.py
  Совместимая точка входа окна. Запускает winopt\ui\app.py; если не
  установлен customtkinter — показывает подсказку, как его установить.

winopt\winutil.py
  Общие помощники Windows: запуск PowerShell без мелькающего окна и в UTF-8,
  проверка прав администратора, перезапуск от администратора, открытие
  файлов и папок, форматирование размеров, скорости и времени,
  папка данных %LOCALAPPDATA%\WinOpt.

winopt\history.py
  Журнал действий программы (history.jsonl): запись, чтение, очистка.

winopt\recycle.py
  Удаление в Корзину (с возможностью восстановления), размер Корзины,
  очистка Корзины. Использует штатные функции Windows (shell32).

winopt\shortcut.py
  Ярлык «Оптимизация Windows» на рабочем столе (включая OneDrive),
  запуск через pythonw.exe без консоли.


ПАПКА winopt\ui\ — ИНТЕРФЕЙС
================================================================================

winopt\ui\theme.py
  Цветовая палитра, шрифты (Segoe UI, Cascadia Mono), значки
  Segoe Fluent Icons, стиль таблиц.

winopt\ui\widgets.py
  Общие элементы интерфейса: кнопки, карточки, плитки показателей,
  кольцевой индикатор с анимацией, линейный график, полоса заполнения,
  таблица с сортировкой и галочками, диалоги подтверждения.

winopt\ui\app.py
  Главное окно: боковое меню с метками, строка состояния с живыми CPU/RAM/сеть,
  фоновые задачи (окно не «зависает»), общий анализ системы для
  рекомендаций, точка восстановления перед изменениями.

winopt\ui\pages\__init__.py
  Список разделов окна.

winopt\ui\pages\dashboard.py     — «Панель»
winopt\ui\pages\optimize.py      — «Оптимизация»
winopt\ui\pages\processes.py     — «Процессы»
winopt\ui\pages\startup.py       — «Автозагрузка»
winopt\ui\pages\cleanup.py       — «Очистка»
winopt\ui\pages\disk.py          — «Диски и файлы» (обзор, папки, большие файлы,
                                   дубликаты)
winopt\ui\pages\programs.py      — «Программы»
winopt\ui\pages\services.py      — «Службы»
winopt\ui\pages\network.py       — «Сеть»
winopt\ui\pages\security.py      — «Безопасность»
winopt\ui\pages\health.py        — «Здоровье ПК»
winopt\ui\pages\journal.py       — «Журнал»


МОДУЛИ: ПРОЦЕССЫ И БЕЗОПАСНОСТЬ
================================================================================

winopt\processes.py
  Сведения о процессах; ProcessMonitor — живой список для раздела «Процессы»;
  проверка, можно ли безопасно завершить процесс (системные — нельзя).

winopt\heuristics.py
  Эвристики подозрительности: подделки системных имён, запуск из Temp,
  проблемы с цифровой подписью. Не антивирус.

winopt\meta.py
  Подпись Authenticode, издатель, описание и версия exe-файлов.

winopt\defender.py
  Статус Защитника Windows, быстрая проверка в фоне, открытие
  «Безопасности Windows».

winopt\restore.py
  Точки восстановления: проверка и создание (нужен администратор).


МОДУЛИ: АВТОЗАГРУЗКА И СЛУЖБЫ
================================================================================

winopt\startup.py
  Чтение автозагрузки: реестр Run, папка Startup, задачи планировщика.
  pretty_name() — короткое имя задачи для показа.

winopt\actions.py
  Отключение и возврат автозагрузки, журнал disabled.json.

winopt\advice.py
  Оценка пунктов автозагрузки: что можно отключить и почему.

winopt\services.py
  Сторонние службы по категориям: обновляторы (можно «Вручную»), прочие,
  оборудование и антивирусы (заблокированы). Возврат прежнего режима
  через services_changed.json.


МОДУЛИ: ОЧИСТКА, ДИСКИ, ДИАГНОСТИКА
================================================================================

winopt\cleanup.py
  Категории очистки в разрешённых папках: TEMP (старше 24 ч), дампы и отчёты
  об ошибках, кэш WinINet, журналы Windows, кэши браузеров, Корзина.
  Сначала подсчёт размера, потом очистка; занятые файлы пропускаются.

winopt\optimize.py
  План и выполнение «быстрой оптимизации», текстовый отчёт в reports\.

winopt\duplicates.py
  Поиск одинаковых файлов (от 256 КБ): сначала по размеру, затем по хешу
  начала файла, затем по полному хешу. Самый старый файл в группе остаётся.
  Удаление — в Корзину.

winopt\disk.py
  Список дисков, крупнейшие папки на выбранном диске, поиск больших файлов.

winopt\system.py
  Живые замеры (CPU, память, сеть, диск, батарея) для графиков,
  сведения о системе, индекс здоровья и рекомендации.

winopt\health.py
  Состояние SSD/HDD (SMART через Windows Storage) и износ батареи
  (powercfg /batteryreport).

winopt\network.py
  Активные TCP-подключения с привязкой к процессу.

winopt\programs.py
  Обычные программы (реестр) и приложения Магазина (AppX), категории из
  обзора, правила защиты (что нельзя удалять), план удаления для окна
  подтверждения, удаление одного пункта (деинсталлятор или
  Remove-AppxPackage) с проверкой результата.

data\programs-review.csv
  Обзор программ (категории A — лишнее, B — на ваше усмотрение, C — оставить).
