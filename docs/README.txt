  ОПТИМИЗАЦИЯ WINDOWS (WinOpt) — документация
  Версия программы: 1.1.0
================================================================================

ОБЩЕЕ ОПИСАНИЕ
--------------
WinOpt — программа для диагностики и бережной оптимизации Windows.
Начиная с версии 1.0.0 у неё новый интерфейс: тёмная «приборная панель»
с живыми графиками, кольцевыми индикаторами и боковым меню.

Программа НЕ является антивирусом и ничего не меняет без вашего
подтверждения. Файлы удаляются только в Корзину (кроме временных файлов
и кэшей — они не нужны и восстанавливать их незачем).

Основные возможности:
  • живая панель: CPU, память, диск, сеть, графики за 90 секунд,
    индекс здоровья ПК и рекомендации «что сделать сейчас»;
  • быстрая оптимизация в один клик (только безопасная очистка + отчёт);
  • диспетчер процессов с безопасным завершением;
  • управление автозагрузкой с оценкой влияния и возвратом отключённого;
  • очистка: TEMP, дампы сбоев, кэши браузеров, Корзина и др.;
  • диски и файлы: обзор дисков, крупные папки, большие файлы, дубликаты;
  • установленные программы: поиск, фильтры, запуск штатного удаления;
  • службы: перевод обновляторов в «Вручную» и возврат обратно;
  • сеть: график трафика и подключения программ;
  • безопасность: Защитник Windows, точка восстановления, проверка процессов;
  • здоровье ПК: износ батареи, состояние SSD/HDD (SMART), сведения о системе;
  • журнал всех действий программы.

Чего программа НЕ делает:
  • не «чистит реестр»;
  • не удаляет программы сама (запускает их штатный деинсталлятор);
  • не трогает системные процессы, службы драйверов и антивируса;
  • не заменяет антивирус.


КАК ЗАПУСТИТЬ
--------------
1. Ярлык «Оптимизация Windows» на рабочем столе (окно без чёрной консоли).
   Если ярлыка нет, программа создаст его сама при запуске
   (существующий ярлык больше не перезаписывается), или командой:
     python -m winopt shortcut

2. Из папки проекта в командной строке:
     python -m winopt                       — открыть окно программы
     python -m winopt gui --page health     — открыть сразу нужный раздел
   Разделы: dashboard, optimize, processes, startup, cleanup, disk,
   programs, services, network, security, health, journal.

3. Консольные команды — см. раздел «Команды CLI».

Права администратора нужны для: изменения служб, создания точки
восстановления, очистки Windows\Temp и журналов, температуры/износа SSD.
Кнопка «Перезапуск от администратора» в левом нижнем углу перезапускает
программу с повышенными правами (Windows спросит подтверждение).


УСТАНОВКА ЗАВИСИМОСТЕЙ
----------------------
Один раз выполните в папке проекта:
  python -m pip install -r requirements.txt

Нужны Python 3.10 или новее и Windows 10/11.
Библиотеки: psutil (данные о системе) и customtkinter (современный интерфейс).
Если customtkinter не установлен, программа покажет окно с подсказкой.


РАЗДЕЛЫ ОКНА ПРОГРАММЫ
----------------------
Панель          — кольцевые индикаторы CPU, памяти, системного диска и
                  индекса здоровья (0–100); график нагрузки за 90 секунд;
                  скорость сети и диска; топ программ по памяти; заполненность
                  всех дисков; рекомендации с переходом в нужный раздел.

Оптимизация     — «быстрая оптимизация»: показывает, сколько места
                  освободится, и очищает только безопасные категории.
                  Автозагрузку и службы здесь НЕ меняет — только советует.
                  После выполнения сохраняется текстовый отчёт.

Процессы        — обновляется каждые 3 секунды. Поиск, фильтры «Мои программы»
                  и «Тяжёлые», группировка по имени (например, все chrome.exe).
                  «Завершить процесс…» — с подтверждением и только для ваших
                  программ: системные процессы и процессы из папки Windows
                  завершить нельзя. «Открыть расположение» — файл в Проводнике.

Автозагрузка    — программы и задачи, стартующие вместе с Windows,
                  с оценкой влияния на загрузку. Отключение не удаляет
                  программу; внизу — список отключённого с кнопкой «Вернуть».
                  Защитник Windows отключить нельзя.

Очистка         — категории с размером ДО удаления: временные файлы
                  (только старше 24 часов), дампы сбоев и отчёты об ошибках,
                  кэш WinINet, журналы Windows, кэши браузеров (Chrome, Edge,
                  Яндекс, Brave, Vivaldi, Opera, Firefox — пароли, история и
                  вкладки НЕ удаляются; открытый браузер пропускается),
                  Корзина. Ссылки на «Очистку диска» и «Контроль памяти».

Диски и файлы   — четыре вкладки:
                  «Обзор дисков» — свободное место на каждом диске;
                  «Крупные папки» — что занимает место (от 100 МБ);
                  «Большие файлы» — файлы от 250 МБ в ваших папках и на других
                  дисках (системные папки не сканируются);
                  «Дубликаты» — одинаковые файлы, в каждой группе оставляется
                  самый старый; удалить все копии сразу программа не даст.
                  Всё удаляется в Корзину и только после подтверждения.

Программы       — обычные программы (реестр HKLM, WOW6432Node, HKCU) и приложения
                  Магазина в одном списке. У каждой строки — галочка.
                  Колонка «Оценка» берётся из обзора программ
                  (data\programs-review.csv): «лишнее» (A) и «на ваше
                  усмотрение» (B); заранее ничего не отмечается.
                  Фильтры: Все, Лишнее (A), На усмотрение (B), Магазин,
                  Крупные, Недавние. Поиск и фильтры не сбрасывают галочки.
                  «Удалить отмеченные (N)» → окно со списком и размером →
                  (по желанию) точка восстановления → удаление по очереди:
                  у обычных программ запускается их деинсталлятор (тихий
                  вариант, если он есть), приложения Магазина удаляются
                  командой Remove-AppxPackage для вашей учётной записи.
                  Статус каждого пункта виден в колонке «Статус», итоги —
                  в «Журнале». «Остановить после текущей» прерывает очередь.
                  🔒 Защищены (без галочки): драйверы, Visual C++, .NET,
                  Docker/WSL, антивирусы, компоненты Windows и встроенные
                  приложения, основной Python 3.14.3 и Python Launcher,
                  Cursor, Git, Node.js, Grok Bot, а также скрытые части
                  других программ (удаляются вместе с основной).

Службы          — сторонние службы с автозапуском. Обновляторы можно
                  перевести в «Вручную» (служба запустится, когда понадобится).
                  Службы драйверов, оборудования и антивирусов заблокированы.
                  Внизу — изменённые службы с кнопкой «Вернуть».

Сеть            — график входящего и исходящего трафика, подключения программ
                  к интернету (или все подключения).

Безопасность    — состояние Защитника Windows, быстрая проверка (идёт в фоне),
                  точка восстановления и откат системы, эвристическая проверка
                  запущенных процессов (подписи файлов, подозрительные пути).

Здоровье ПК     — износ батареи (ёмкость сейчас и у новой), подробный отчёт
                  Windows о батарее; состояние SSD/HDD; сведения о системе.

Журнал          — всё, что программа изменила: когда, что и с каким
                  результатом. Кнопки «Папка отчётов» и «Папка данных».


ЧТО ИЗМЕНИЛОСЬ В ВЕРСИИ 1.0.0
-----------------------------
Убрано (и почему):
  • очистка «Недавних файлов» — не ускоряет компьютер, только удаляет
    удобные списки в Проводнике;
  • пометка «подозрительных» программ по словам в названии — давала ложные
    срабатывания (например, «patch», «coin»);
  • массовая рекомендация отключать все сторонние службы — могла сломать
    звук, тачпад или Wi-Fi; теперь рекомендуются только обновляторы;
  • отдельные вкладки «Нагрузка», «Проверка», «Защитник» — объединены в
    «Процессы» и «Безопасность»;
  • медленный «Обзор» с проверкой подписей при каждом запуске — заменён
    живой панелью;
  • удаление дубликатов без Корзины — теперь только в Корзину;
  • перезапись ярлыка при каждом запуске;
  • «тихие» ошибки создания точки восстановления — теперь о них сообщается.

Исправлено:
  • сообщения об ошибках в окне не показывались (ошибка в коде);
  • команда «python -m winopt disk» падала;
  • быстрая проверка Защитником прерывалась через 30 секунд;
  • мелькание чёрных окон PowerShell при работе программы;
  • фильтр «Недавние» в программах сортировал даты неправильно;
  • русские названия служб отображались «кракозябрами».

Добавлено: живая панель и индекс здоровья, быстрая оптимизация, диспетчер
процессов, кэши браузеров и Корзина в очистке, обзор дисков и поиск больших
файлов, удаление программ, возврат служб, график сети, здоровье батареи и
дисков, журнал действий, перезапуск от администратора.


КОМАНДЫ CLI
-----------
  python -m winopt                       открыть окно
  python -m winopt gui [--page РАЗДЕЛ]   открыть окно (сразу на нужном разделе)
  python -m winopt scan                  проверка процессов
  python -m winopt resources             нагрузка CPU/RAM
  python -m winopt startup               список автозагрузки
  python -m winopt cleanup --scan        сколько можно очистить
  python -m winopt cleanup --all --yes   очистка безопасных категорий
  python -m winopt duplicates            поиск повторяющихся файлов
  python -m winopt disk [--drive D:]     крупные папки на диске
  python -m winopt large-files [--min-mb 500]   большие файлы
  python -m winopt health                SSD/HDD и батарея
  python -m winopt history               журнал действий
  python -m winopt network [--external]  сетевые подключения
  python -m winopt programs --filter all|large|recent|no_publisher|A|B|store|removable
  python -m winopt services              службы, которые можно перевести в «Вручную»
  python -m winopt restore-point --yes   точка восстановления (нужен админ)
  python -m winopt report                полный отчёт JSON
  python -m winopt shortcut              создать ярлык на рабочем столе
  python -m winopt --version             версия
  python -m winopt --help                справка


ДАННЫЕ ПРОГРАММЫ НА ДИСКЕ
-------------------------
  %LOCALAPPDATA%\WinOpt\
    history.jsonl         — журнал действий (раздел «Журнал»)
    disabled.json         — отключённая автозагрузка (для возврата)
    startup_files\        — ярлыки, перенесённые из папки Startup
    services_changed.json — изменённые службы и их прежний режим
    reports\              — отчёты быстрой оптимизации (optimize-*.txt)

  data\programs-review.csv (в папке программы) — обзор программ с категориями
    A/B/C для колонки «Оценка» на странице «Программы». Можно заменить
    своим файлом %LOCALAPPDATA%\WinOpt\programs-review.csv.

Отчёт по команде report: winopt-report.json (в текущей папке или --out).


ВАЖНЫЕ ОГРАНИЧЕНИЯ
------------------
• Высокий балл в проверке процессов — повод присмотреться, а не доказательство
  вируса.
• Windows создаёт точки восстановления не чаще одного раза в ~24 часа.
• Кэш браузера очищается, только если браузер закрыт.
• Температура и износ SSD видны не на всех дисках и только с правами
  администратора.
• WSL и Docker программа не удаляет и не настраивает.
